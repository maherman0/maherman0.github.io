# Is Bootstrap 5 Worth it?

As someone who has never heard of Bootstrap 5 before, I came into this all new. For the past week that I’ve learned Bootstrap 5 I’d say it is definitely worth your while to learn the syntax. The setup is minimal as HTML looks up Bootstrap online. Once you’ve inserted it as a link, you’ve unlocked a new form of formatting your website. From having dividers to adding new icons Bootstrap can fill up most of your CSS code that you’ve got to navigate through because Bootstrap has prebuilt layouts for users to add to design their unique websites.From learning bootstrap, I’ve been able to learn about how developers format and frame their websites and apps to fit their own requirements and wants. I’ve learned how to recreate these websites through hints in creating things such as the navbars.


# How Bootstrap Changed Responsive Web Design

From learning Bootstrap I’ve touched on learning the grid system of adding the navigation bars all over the place for flexibility in creating a website that is different for everyone. Some require simple layouts, while others need a more compact layout to allow other sections to shine. One of the main advantages of using Bootstrap is that they allow for easier design especially in making websites for different screen sizes such as on a desktop, ipad, or even a phone. There are so much reusable content on Bootstrap that a developer needs to build up the websites that helps other developers know what others are trying to accomplish as well. 

# Should you use Bootstrap with your CSS?

Now that you know Bootstrap is strong with HTML to potentially replace CSS, should you replace it. Now CSS is still one of the most popular and widely used languages across developers. The amount of control you can have from editing your objects and styling can still be useful for some, but it cannot hurt to simplify some of your code to use bootstrap to create the layout for your website and add any other styling that the user wishes on top of using the grid system. Some prefer to only use HTML, CSS, and Javascript together because of the direct control, while Bootstrap allows you to make your repetitive website easier to create with the built in classes.
